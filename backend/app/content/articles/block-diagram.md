## ブロック線図とは

**ブロック線図（Block diagram）** は、システムを「箱（伝達関数）」と「矢印（信号の流れ）」で描いた図です。複雑なシステムを部品ごとに分け、それらのつながりを視覚的に表します。Simulink のモデルもまさにこのブロック線図そのものです（[[matlab-simulink]] 参照）。

```mermaid
graph LR
  R["目標値 R(s)"] --> S(("＋/−"))
  S --> C["制御器 C(s)"]
  C --> P["制御対象 P(s)"]
  P --> Y["出力 Y(s)"]
  Y -->|"フィードバック"| S
```

## 3つの基本要素

| 要素 | 記号 | 意味 |
|---|---|---|
| **ブロック** | □ の中に \(G(s)\) | 伝達関数。入力に \(G(s)\) を掛けて出力 |
| **加え合わせ点** | ○ に ＋/− | 信号の足し算・引き算（誤差の計算） |
| **引き出し点** | 分岐 | 同じ信号を複数へ分ける |

## 直列・並列・フィードバックの合成

### 直列結合（縦続接続）

ブロックが連なると、伝達関数は **掛け算** になります。

$$
G(s) = G_1(s)\,G_2(s)
$$

### 並列結合

同じ入力を分けて足し合わせると、**足し算** になります。

$$
G(s) = G_1(s) \pm G_2(s)
$$

### フィードバック結合（最重要）

出力を入力に戻す構成。前向き経路 \(G(s)\)、フィードバック経路 \(H(s)\) のとき、閉ループ伝達関数は次の公式で求まります。

$$
\frac{Y(s)}{R(s)} = \frac{G(s)}{1 + G(s)H(s)}
$$

分母の符号は負フィードバック（誤差を減らす向き）のとき \(+\)。この \(1 + G(s)H(s) = 0\) が **特性方程式** で、その根（＝閉ループ極）が系全体の安定性を決めます。

## なぜフィードバックが必要か

開ループ（フィードバックなし）だと、外乱やモデル誤差をそのまま受けてしまいます。フィードバックは「目標と実際の差（誤差）」を測って修正するため、

- **外乱に強い**（風・路面・積載重量が変わっても補正）
- **モデル誤差に強い**（正確な物理モデルが無くても目標に追従）
- **応答特性を設計できる**（速さ・安定性を制御器で調整）

```mermaid
flowchart LR
  R["目標\n（駐車枠の中心）"] --> E(("誤差 e = R − Y"))
  E --> C["制御器\nハンドル・速度指令"]
  C --> V["車両（制御対象）"]
  V --> Y["実際の位置 Y"]
  Y -->|"センサで計測して戻す"| E
```

自動駐車では「目標の駐車位置」と「センサで測った現在位置」の誤差をフィードバックし、ハンドル角と速度を刻々と修正します（[[auto-parking-control]]）。

## 例：閉ループを計算する

比例制御器 \(C(s) = K_p\) と一次系のプラント \(P(s) = \dfrac{1}{Ts+1}\) を負フィードバックで結ぶと、

$$
\frac{Y(s)}{R(s)} = \frac{K_p \cdot \frac{1}{Ts+1}}{1 + K_p \cdot \frac{1}{Ts+1}}
= \frac{K_p}{Ts + 1 + K_p}
$$

$$
= \frac{K_p/(1+K_p)}{\frac{T}{1+K_p}s + 1}
$$

つまり閉ループにすると **時定数が \(T/(1+K_p)\) に短縮**（応答が速くなる）し、極が \(s = -(1+K_p)/T\) と左へ移動して安定性が増します。ゲイン \(K_p\) を上げるほど速くなるのがフィードバックの効果です。

## Python（python-control）で合成する

```python
import control as ct

# プラント P(s) = 1/(2s+1), 比例ゲイン Kp=4
P = ct.tf([1], [2, 1])
Kp = 4
C = ct.tf([Kp], [1])

# 直列 → フィードバック（負帰還）
open_loop = ct.series(C, P)
closed = ct.feedback(open_loop, 1)
print("閉ループ伝達関数:")
print(closed)
print("閉ループ極:", ct.poles(closed))
```

```
閉ループ伝達関数:
   4
-------
2 s + 5

閉ループ極: [-2.5]
```

**数式で表すと**、上の計算はフィードバック公式

$$
\frac{C(s)P(s)}{1 + C(s)P(s)} = \frac{4/(2s+1)}{1 + 4/(2s+1)} = \frac{4}{2s+5}
$$

そのもので、極 \(s = -2.5\)（開ループの \(-0.5\) より左）へ移り、応答が速く・安定になったことを表します。

## 等価変換のルール

ブロック線図は次の規則で簡単化できます（Simulink で複雑なモデルを読む際にも役立つ）。

| 変形 | 内容 |
|---|---|
| 直列の統合 | 掛け算 \(G_1 G_2\) にまとめる |
| 並列の統合 | 足し算 \(G_1 \pm G_2\) にまとめる |
| フィードバックの統合 | \(\dfrac{G}{1+GH}\) にまとめる |
| 加え合わせ点の移動 | ブロックの前後で符号・ゲインを調整 |

## まとめ

- ブロック線図はシステムを箱（伝達関数）と矢印（信号）で描く言語
- 直列 → 掛け算、並列 → 足し算、フィードバック → \(\dfrac{G}{1+GH}\)
- 特性方程式 \(1 + G(s)H(s) = 0\) の根が閉ループ極 → 安定性を決める
- フィードバックは外乱・モデル誤差に強く、応答特性を設計できる
- この考え方を実装する環境が [[matlab-simulink]]、応用が [[control-engineering]]
