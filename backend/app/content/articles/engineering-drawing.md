## 概要
図面（製図）はエンジニアの共通言語です。自動車のエンジンブロック・サスペンションアーム・ハーネスコネクタなど、すべての部品は図面から作られます。図面を読む力は設計・生産・品質・実験すべての職種で必要とされます。

## 図面の種類

```
自動車開発で使われる図面の種類:

  部品図（Detail Drawing）
  ├── 外形図：外形寸法だけ（納品仕様書向け）
  ├── 機械図：材質・加工精度を含む製造用図面
  └── 電気図：ハーネス・回路図

  組立図（Assembly Drawing）
  ├── 構成を示す（どの部品がどこに付く）
  └── 分解図（Exploded View）

  工程図（Process Drawing）
  └── 製造工程・検査手順
```

## 三角法（第一角法 vs 第三角法）

```python
# 図の投影法を理解する
# 日本・EU: 第一角法（ISO）
# 米国・JIS旧来: 第三角法（ASME）→ 現在JISも第三角法推奨

"""
第三角法（JIS推奨）の配置:

         [上面図]
            ↑
  [左側面図] [正面図] [右側面図]
            ↓
         [下面図]

  → 展開した面が「その方向から見た図」になる
  → 「右から見た図は右に置く」

第一角法（ISO/EU）:
  → 「右から見た図は左に置く」（反対）
"""

# 図面の記号で判断
symbols = {
    "第三角法": "○の中に△（矢印が外向き）",
    "第一角法": "○の中に台形（矢印が内向き）",
}
for method, symbol in symbols.items():
    print(f"{method}: {symbol}")
```

## 寸法線・公差の読み方

```
寸法の記法:

  50 ± 0.1      →  50mm, 許容差 ±0.1mm
  50 +0.05/-0   →  50mm〜50.05mm（一方向公差）
  50h7          →  50mm, はめあい公差 h7（軸）
  50H7          →  50mm, はめあい公差 H7（穴）
  φ20           →  直径 20mm
  R5            →  半径 5mm
  □30           →  正方形 30mm × 30mm
```

```python
# はめあい公差の計算（JIS B 0401）
# 自動車のシャフト・ベアリングの嵌合に多用

def fit_tolerance(nominal, hole_code, shaft_code):
    """
    穴と軸のはめあい公差（概略値）
    nominal: 基準寸法 [mm]
    """
    # IT公差グレードの概略（50mm基準）
    IT_grades = {
        5: 0.011, 6: 0.016, 7: 0.025, 8: 0.039, 9: 0.062
    }

    # 代表的なはめあい
    fits = {
        "H7/g6": ("すきまばめ", "回転・摺動部（軸受など）"),
        "H7/k6": ("中間ばめ",  "位置決め（軽圧入）"),
        "H7/p6": ("しまりばめ","圧入固定（リング・ブッシュ）"),
        "H7/n6": ("中間ばめ",  "ノック穴・位置決めピン"),
    }

    for fit, (fit_type, usage) in fits.items():
        print(f"  {fit:8s} → {fit_type}（{usage}）")

print("自動車部品の代表的なはめあい:")
fit_tolerance(50, "H", "7")
```

## 表面粗さ（仕上げ記号）

```
表面粗さ記号:

  Ra 0.8  → 算術平均粗さ 0.8μm（研削仕上げ）
  Ra 1.6  → 旋削・フライス仕上げ
  Ra 3.2  → 一般的な切削加工
  Ra 6.3  → 粗削り
  Ra 25   → 鋳物・プレス素材のまま

自動車部品の代表例:
  エンジンシリンダーボア: Ra 0.4〜0.8（ホーニング仕上げ）
  クランクシャフトジャーナル: Ra 0.2〜0.4（研削）
  ギアの歯面: Ra 0.8〜1.6（研削・シェービング）
  外装パネル: Ra 1.6〜3.2（プレス後塗装）
```

```python
# 加工方法と表面粗さの対応
machining_roughness = {
    "超精密研削（ラッピング）": (0.006, 0.025),
    "研削（Grinding）":        (0.025, 0.8),
    "ホーニング":               (0.1,  0.8),
    "旋削・フライス（精）":    (0.4,  3.2),
    "旋削・フライス（粗）":    (3.2, 12.5),
    "プレス・鍛造":             (1.6, 12.5),
    "鋳造":                    (6.3, 25.0),
}
for process, (ra_min, ra_max) in machining_roughness.items():
    print(f"  {process:25s}: Ra {ra_min}〜{ra_max} μm")
```

## GD&T（幾何公差）

寸法公差だけでは表現できない形状・位置の誤差を規定します。

```
幾何公差記号と意味:

  ⊙  真円度      → 断面の真円からの誤差
  ⌭  円筒度      → 円柱全体の誤差
  //  平行度      → 基準面との平行性
  ⊥  直角度      → 基準面との垂直性
  ◎  同軸度      → 基準軸との同心度
  ⊕  位置度      → 理論的位置からのずれ
  ↗  面の輪郭度  → 自由曲面の誤差
```

```python
# 自動車エンジンの幾何公差例
engine_tolerances = [
    ("シリンダーボア真円度",    "⊙", "0.005 mm", "ピストンリングのシール性"),
    ("クランクシャフト同軸度",  "◎", "0.010 mm", "振動・ベアリング寿命"),
    ("シリンダーヘッド面平面度","⊠", "0.050 mm", "ガスケットのシール性"),
    ("カムシャフト位置度",      "⊕", "0.020 mm", "バルブタイミング精度"),
]

print(f"{'部品':25s} {'公差記号':6s} {'値':10s} {'理由'}")
print("-" * 70)
for part, symbol, tol, reason in engine_tolerances:
    print(f"{part:25s} {symbol:6s} {tol:10s} {reason}")
```

## 電気図面（配線図・回路図）

```
自動車の電気図面の種類:

  回路図（Schematic）
  └── 電気的な接続を記号で表す
      コンポーネント記号: バッテリー=⊣⊢, ヒューズ=□

  配線図（Wiring Diagram）
  └── 実際の配線経路・色・端子番号を示す
      例: B+ -- 0.5 R/W -- C01-3 -- ヒューズ15A --

  ハーネス図（Harness Drawing）
  └── ワイヤーハーネスの束・クリップ・グロメット位置
```

```python
# ワイヤーハーネスの仕様読み取り例
# コネクタピン配置: 「C01-3」= コネクタC01の3番ピン
# 線色コード（日本自動車メーカー例）
wire_colors = {
    "B":  "黒（Black）  → GND, 接地",
    "R":  "赤（Red）    → B+電源",
    "W":  "白（White）  → 信号",
    "G":  "緑（Green）  → 信号",
    "Y":  "黄（Yellow） → 信号",
    "L":  "青（Blue）   → 信号",
    "Br": "茶（Brown）  → 信号",
    "P":  "ピンク       → イグニッション電源",
    "O":  "橙（Orange） → ACC電源",
}
for code, meaning in wire_colors.items():
    print(f"  {code:3s}: {meaning}")

print("\n複合色の読み方:")
print("  R/W = 赤地に白ストライプ（Red with White stripe）")
print("  G/Y = 緑地に黄ストライプ")
```

## 部品番号・改訂管理

```
図面の標識欄（Title Block）の読み方:

  ┌─────────────────────────────┐
  │ 品番: 12345-67890            │  ← 部品番号（13桁など）
  │ 品名: シリンダーヘッドカバー   │
  │ 材質: ADC12（アルミダイカスト）│
  │ 図面番号: DWG-2024-001 Rev.C  │  ← Rev=改訂番号
  │ 縮尺: 1:2                    │  ← 実物の1/2サイズで描画
  │ 単位: mm                     │
  │ 設計: 山田太郎 2024.03.15    │
  │ 承認: 鈴木花子 2024.03.20    │
  └─────────────────────────────┘

Rev管理:
  Rev.A → 初版
  Rev.B → 1回目の変更（マイナー修正）
  Rev.C → 2回目の変更
  ※ Rev.が上がると旧版は廃止
```
