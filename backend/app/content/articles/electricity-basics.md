## 概要
電気は現代のあらゆるテクノロジーの基盤です。スマートフォン・車・コンピューターはすべて電気で動いています。「なぜ電気が流れるのか」を原子レベルから理解することが、電子工学・組み込み開発・車載ECU設計の出発点です。

## 原子と電子

```
原子の構造:

       ○  ←── 陽子（+の電荷）
      核  ←── 中性子（電荷なし）

    ●       ←── 電子（−の電荷）
  （軌道を回る）
```

物質はすべて**原子**でできています。原子の中心（原核）には**陽子（+）と中性子**があり、その周りを**電子（−）**が回っています。

- 陽子と電子の数が同じ → 電気的に中性
- 電子が1個少ない → プラスに帯電（正イオン）
- 電子が1個多い → マイナスに帯電（負イオン）

## 自由電子と電気伝導

銅や鉄などの**金属**では、一部の電子が原子の束縛を離れて自由に動ける**自由電子**になっています。

```
金属の内部イメージ:

  Cu²⁺  Cu²⁺  Cu²⁺  Cu²⁺
    ●→    ●→    ●→    ●→   ← 自由電子がドリフト
  Cu²⁺  Cu²⁺  Cu²⁺  Cu²⁺
    ●→    ●→    ●→    ●→
```

電圧をかけると自由電子が一方向に流れる。これが**電流**です。

## 電流（I）

**電流**とは、単位時間あたりに流れる電気の量です。

$$I = \frac{Q}{t}$$

- **I**：電流 [A（アンペア）]
- **Q**：電荷量 [C（クーロン）]
- **t**：時間 [s（秒）]

```
注意：電流の向きと電子の向きは逆！

電流の向き: +極 →→→→→→ −極
電子の向き: +極 ←←←←←← −極
```

歴史的に電流の向きは「+から−に流れる」と定義されましたが、実際に動いているのは−の電子で、−極から+極に移動します。

## 電圧（V）

**電圧**（電位差）とは、電子を動かす「押し出す力」です。水の流れに例えると「水位の差（位置エネルギーの差）」に相当します。

```
水の流れのアナロジー:

 高い水位             低い水位
 ［水タンク］─────── ─────────
               ↓↓↓ 水流（＝電流）
 ─────────────────────────────
```

- 単位：V（ボルト）
- 乾電池1本：1.5V
- 家庭用コンセント：100V（日本）
- 車載システム：12V または 48V

## 抵抗（R）

**抵抗**は電流の流れにくさを表します。電子が原子に衝突することで生じます。

- 単位：Ω（オーム）
- 抵抗が大きい → 電流が流れにくい
- 抵抗が小さい → 電流が流れやすい

```python
# 代表的な材料の抵抗率（20°C）
resistivity = {
    "銀（Ag）":    1.59e-8,   # Ω·m（最良導体）
    "銅（Cu）":    1.72e-8,   # 電線によく使われる
    "アルミ（Al）": 2.82e-8,
    "鉄（Fe）":    1.00e-7,
    "シリコン":    6.40e+2,   # 半導体
    "ガラス":      1.00e+12,  # 絶縁体
}

for mat, rho in resistivity.items():
    print(f"{mat:15s}: {rho:.2e} Ω·m")
```

## 導体・半導体・絶縁体

| 種類 | 抵抗率 | 例 |
|---|---|---|
| 導体 | 10⁻⁸〜10⁻⁶ Ω·m | 銅、アルミ、金 |
| 半導体 | 10⁻⁴〜10⁴ Ω·m | シリコン、ゲルマニウム |
| 絶縁体 | 10⁸〜10¹⁶ Ω·m | ガラス、ゴム、プラスチック |

## まとめ

```
電気の3要素:

  電圧 V ─── 電子を動かす「力」（単位: V）
  電流 I ─── 流れる電気の量（単位: A）
  抵抗 R ─── 流れにくさ（単位: Ω）

  これら3つの関係を表すのが → オームの法則
```
